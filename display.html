如何安裝描述檔

macOS

  1. 把 .icc 檔放到 ~/Library/ColorSync/Profiles/。
  2. 系統設定 → 顯示器 → 顏色描述檔 → 選擇剛才的描述檔。macOS 會自動載入其中的 vcgt 校正曲線。

Windows 10/11

  1. 開啟「色彩管理」（colorcpl）→ 勾選「使用此裝置的設定」→ 新增 → 選 .icc → 設為預設描述檔。
  2. 「進階」頁籤 → 變更系統預設值 → 勾選「使用 Windows 顯示器校正」，vcgt 才會被載入顯示卡。
  3. 若開啟 Windows 11「自動管理應用程式色彩」，請確認描述檔仍為預設。

Linux

  1. GNOME：設定 → 色彩 → 加入描述檔；或用 ArgyllCMS dispwin -I 檔名.icc 安裝並載入 vcgt。

安裝後可重新執行一次量測（先依步驟 1 把描述檔換回 sRGB 再量），或保留此頁做驗證。
